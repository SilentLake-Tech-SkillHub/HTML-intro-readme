# 制作标准

## 文案与信息

面向第一次看到项目的人，按用户指定的问题和顺序讲清楚。先定稿再实现；一屏一句主话加一段解释，其余信息通过真实配图、标签、提示词或必要表格承载。

保留作者“我”、用户“你”和已批准的语气。减少抽象口号，直接说明操作、收益和使用场景。完整教程始终可达，动画上的关键安装和启动信息足够实际使用；正文过长应拆屏或延时，不能只缩字号。

已有文案逐字校对，包括标点、全角括号、工具名和空格。视觉换行不能吞掉英文前后的空格。

## 视觉

默认可采用本次实作的白底、黑灰正文、`#f15332` 强调色；已有品牌要求时以品牌为准。颜色服务于重点，避免大面积高饱和色吞没文字和截图。

桌面 16:9，主句通常 32–54px，说明约 16–19px；手机主句约 30px，说明约 15–16px。按字量调整，避免孤立短尾行和生硬断句。

390px 改为单列。密集路径表转为逐行卡片，长路径允许换行。页面可随内容纵向增高，但不能横向滚动、裁切信息，或在桌面单屏内套滚动条。

截图保留原有遮挡和原件；缩略图可裁切，点击后能看完整图。大图和叠放小图的图注都要可见。阶段线和成果卡片的阶段颜色一致。工具使用可辨识图标，提供 alt / title / 可访问名称，并保留许可。

## 时间轴与动效

把整片位置作为唯一动画时钟：累计时长定位当前屏，减去该屏起点得到 `localTime`。入场、条形图增长和过渡箭头都由它定位。推荐暂停的 Web Animations，逐帧设置 currentTime；独立 CSS 动画容易在拖动和暂停时不同步。

```js
const animation = element.animate(keyframes, {
  delay: appearAt * 1000, duration: 700, fill: 'both'
});
animation.pause();
// 每帧、拖动和暂停定位都用同一个本屏时间：
animation.currentTime = localTime * 1000;
```

标准速度依据定稿；慢速 ×1.5 作用于整条时间轴，包括全部入场和过渡。手动模式直接显示本屏所有内容，隐藏过渡提示。点章节或左右翻屏可进入手动阅读，点播放恢复自动。有效锚点打开后直接显示目标内容。

入场通常淡入上移约 18px / 0.7 秒；文件卡等特殊画面可使用有意义的落下效果。错峰时刻写入分镜。过渡提示通常在结束前约 1.7 秒出现，文字对应实际下一段。暂停时箭头也要停住。

按字量核对停留时间，可按约 7–10 个中文字/秒粗估后人工阅读。提示词与路径表可暂停、手动阅读和复制。示例中的 12 屏、89 秒仅是案例参数。

## 播放器

提供可拖动进度、上一屏、播放/暂停、下一屏、重播、时间码、标准/慢速/手动、章节导航和全屏。手动显示“第 N / 总数 屏”，自动显示当前/总时长。

空格播放/暂停，左右翻屏；输入框、选择器和图片弹窗内不抢占键盘操作。点图片或复制自动暂停；弹窗可关闭，复制失败可手动选择。

系统减少动态效果时，默认手动，元素立即显示。非当前屏不可获得焦点；键盘焦点清楚，图片有替代文字，复制结果有可访问提示。

页眉显示项目名、短说明、屏数与总时长，并提供指南和仓库入口。页脚提供操作提示、来源版本、完整 Q&A 和图标许可。锚点使用稳定 key，同时处理首次打开和页面内 hashchange；本案例保留 install、start、ratings、showcase 四个入口。

## 评分与 PNG

数据取自用户或可核实来源。准确显示工具、分数与尺度；满分 100 时使用 0–100 横轴，不截断来放大差异。第一条可用强调色，其余深灰；条长与数值成正比。

作者体验评分注明主观性质、综合维度和“非官方基准”。不编造分项分数、权重、样本或测试结论。需要单独 PNG 时输出清晰版本，例如 1800×1200，并实看标签、数值和刻度。

## 离线与来源

单个 HTML 移到没有同伴文件的临时目录，关闭网络再打开。图片、图标、必要指南、提示词和许可仍能使用；自动加载没有 HTTP 请求。外部仓库链接只在用户主动点击时跳转。

原始图片与来源清单 SHA-256 一致。不以补全、提高清晰度等方式恢复遮挡，不把课程原资料、私有页面或用户凭据顺带打包到公开技能仓库。

## 视频版（HTML 完成后可选）

先完成 HTML 制作和验收，用户要求视频版时再进行以下检查。视频复用已确认的网页版本、顺序、文案、截图和统一动画时钟。按帧率固定时间步长渲染，默认输出 16:9、1080p、30 fps、H.264 MP4；可选择 4:3 / 3:4 / 16:9 / 9:16、720p / 1080p / 4K、30 / 60 / 120 fps 的组合。默认等比留白，按目标比例重排需使用项目适配排版。声音状态明确记录，不默认添加配音配乐。

视频源文件、参数、片段范围与来源哈希可追溯。优先利用可用的系统编码能力，指定硬件编码失败时明确报错，未测硬件状态不宣称已启用或推断加速倍数。先跑短片，再做需要的完整导出。具体接口与工具见 [video-export.md](video-export.md)。

编码完成后全部帧可解码，帧数、帧率、时间戳、尺寸和时长与预期一致；按屏抽帧并实际检查安装页、评分、成品图和隐私遮挡。人工复看入场和过渡，不能把静态截图拼接声称为原动画复现。原 HTML 保持可用。

## 交付验收

每项记录实测证据；未检查不得写“通过”。

| 检查 | 通过条件 |
|---|---|
| 来源与文案 | 当前来源、版本完整；正文、提示词、路径、导航与定稿一致 |
| 顺序与时长 | 导航、实际播放、稳定锚点和过渡一致；累计时长等于定稿 |
| 桌面 / 手机 | 1440×900、390×844 逐屏截图；无横向滚动、裁切或越界 |
| 密集信息 | 桌面完整显示、无屏内滚动；手机表格为卡片、长路径换行 |
| 动效定位 | 拖至中途，已到时元素立即显示，未到时元素仍未出现 |
| 暂停 | 入场、评分条和过渡箭头全部冻结；恢复位置连续 |
| 控制 | 慢速 ×1.5；手动全显示；末尾停住；重播归零；键盘、全屏正常 |
| 复制与放大 | 两段提示词复制原文一致；点击自动暂停；弹窗显示完整原图 |
| 减少动态效果 | 默认手动，所有元素可读 |
| 评分 | 原始值、0–满分刻度、条长一致；独立 PNG 实看无误 |
| 独立离线 | 无同伴文件、断网；图片、图标、指南和许可可用，无自动 HTTP 请求 |
| 日志 | 无控制台错误和缺失资源 |
| 本地交付 | 入口存在、可打开；源码、来源、定稿、检查记录齐备，旧版已区分 |
| 视频（用户要求时） | 来源版本正确；全部帧解码、时长、帧数、尺寸、时间戳通过；逐屏实看，入场与过渡正确，声音状态与硬件状态如实记录 |
| GitHub（已授权时） | 仅同步技能所需文件，远端 SHA 和关键文件核对一致 |
